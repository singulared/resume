# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- `resume` CLI: `generate` (markdown, HTML, PDF), `list`, `check` and `stars` (GitHub star cache)
- HTML/PDF design from the claude-design resume project: embedded IBM Plex fonts, a warm paper palette, Minimal/Editorial/Punk styles and light/dark themes behind an on-page menu; `--style` picks the default
- Attribute-driven derives (`Project`, `Work`, `Oss`, `Conference`, `Education`, `Publication`, `Profile`, `Interest`) feeding the views from the same source as the rustdoc
- Moka contribution
- Profile summary as the intro of the views and of the front page; `resume check` verifies they match

### Changed
- Work history generated by `#[derive(Project)]` instead of hand-written trait impls
- Views take companies and projects from the `WorkHistory` enum (`#[derive(Work)]`) in declaration order; Rambler's projects now lead with News
- Display names for projects, open-source repos and technologies in the views (e.g. Domain Engine, actix-web-validator, PostgreSQL, C#)
- Star counts shown as text (★ 2.6k) instead of shields.io badges; zero counts hidden
- resume-macro ported to syn 2 and darling
- Toolchain pinned to nightly-2026-10-07; CI checks pull requests and deploys only from main
- Language pass over the resume content; concrete scope for the Digital Wave and Rambler roles

### Fixed
- Build on current nightly (`associated_const_equality` feature removed)
- Co-author name, RustCon 2022 role and PyCon talk topic
- Nested lists in doc comments survive into the views
- Rustdoc intra-doc links render as plain text in the views

### Removed
- Prototype derives `ResumeWork`, `ResumeProject` and `ResumeOpenSource`
- `Company` derive, the private company mirror and `#[project(parent = ...)]`
- Skill badges from the front page; birth date from the views
